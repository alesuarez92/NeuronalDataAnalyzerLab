NeuroAnalyzer: step-by-step analysis windows for blood flow, electrophysiology and imaging

NeuroAnalyzer (repository NeuronalDataAnalyzerLab) is a MATLAB toolbox with one window per analysis step: Laser Doppler flowmetry (LDF), local field potentials (LFP), multi-unit activity (MUA), image stacks and response features. Every window can open synthetic demo data with known answers, so you can check the results before using your own recordings.

Screenshots taken by the automated tests, which drive every window on the demo data in real MATLAB. Use the arrow keys or the buttons to move through them.

Every window works the same way

1 Load→2 Settings→3 Run→4 Save
  • Numbered step cards on the left, plots on the right. The teal button is the suggested next action; buttons that are not possible yet are greyed out.
  • The status bar at the bottom says what happened and what to do next.
  • ? Help in each window header opens its quick start and troubleshooting (the same text as the guide).
  • Try demo data opens the window with synthetic data whose answers are known; the demo data page lists them.
  • Each step saves a .mat file that the next step loads, so pipelines can be stopped and resumed.

Checked against known answers

The demo recordings are generated by the toolbox with a fixed random seed and store their ground truth. The test suite runs every analysis on them, and on analytic and textbook examples, and checks the results within stated tolerances. What the tests check.

Get started

  1. Download the latest release and add it to the MATLAB path (Install).
  2. Run NeuroAnalyzer, click Set folders, then open a window from a card.
  3. Click Try demo data in that window and compare your numbers with the guide.
