About NeuroAnalyzer

A MATLAB analysis toolbox from the NMD Lab by Alejandro Suarez, Ph.D.

Author

NeuroAnalyzer is written and maintained by Alejandro Suarez, Ph.D. (NMD Lab; GitHub). The explanatory figures on this site and in the in-app Help are his own. Questions, bugs and feature requests: GitHub issues.

How to cite

If you use NeuroAnalyzer in published research, please cite the software (from CITATION.cff; GitHub also offers "Cite this repository"):

Suarez A. NeuronalDataAnalyzerLab (version 0.1.0) [software]. Released 2026-05-07. https://github.com/alesuarez92/NeuronalDataAnalyzerLab

@software{Suarez_NeuronalDataAnalyzerLab,
  author  = {Suarez, Alejandro},
  title   = {NeuronalDataAnalyzerLab},
  version = {0.1.0},
  date    = {2026-05-07},
  url     = {https://github.com/alesuarez92/NeuronalDataAnalyzerLab}
}

Please also cite the method papers for the analyses you report; they are listed on the references page.
