Install

Install NeuroAnalyzer

Download a tagged release, add it to the MATLAB path and launch it with NeuroAnalyzer.

Steps

  1. Download the release ZIP from Releases (Source code (zip)). Use Releases rather than the green Code → Download ZIP button: that button gives the in-development main branch.
  2. Unzip it somewhere stable, for example ~/Documents/MATLAB/NeuronalDataAnalyzerLab.
  3. Add it to the path once, in the MATLAB Command Window: 
    addpath(genpath('~/Documents/MATLAB/NeuronalDataAnalyzerLab'));
savepath;   % optional: keep it for future sessions
  4. Launch: 
    NeuroAnalyzer
    The launcher asks for an Import folder (raw data) and an Export folder (results) the first time. Both are stored as MATLAB preferences.

Check the installation

  • The launcher status bar says whether the Signal Processing Toolbox and the TDT SDK were found.
  • Click Try demo data in any window and compare the result with the window's "Demo data" section in the guide.
  • Optional: run the test suite from the toolbox folder with run_tests. Tests that need a display or a missing toolbox are skipped.

TDT MATLAB SDK (only for TDT tanks)

The Tucker-Davis Technologies SDK is a separate, third-party toolbox with its own licence and is not included.

  1. Download it from tdt.com/support/matlab-sdk and unzip it.
  2. Place the TDTMatlabSDK/ folder under Utilities/, so that Utilities/TDTMatlabSDK/TDTSDK/ exists.
  3. Restart MATLAB. Extract Ephys adds the SDK to the path when it is needed. The folder is ignored by git, so updates do not touch it.

Update

Download the new release ZIP, replace the contents of the same folder (the path stays the same) and launch again. To follow development instead, clone the repository into that folder:

git clone https://github.com/alesuarez92/NeuronalDataAnalyzerLab.git

Report bugs and ideas through GitHub issues rather than keeping a fork; see the licence.
